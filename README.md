# Test Metrics Analyzer
Parsing and plotting of test results. It extracts raw data from JSON reports (e.g. generated by pytest-json-report) and transforms it into visual insights using Matplotlib

*   **JSON Parsing:** Automated extraction of test results, execution times, and status counts from `report.json`.
*   **Data Visualization:** Generates informative plot

### Preconditions

-   **Update src\config.py**

### Execution
-   **Create virtual environment (if not already created):**
    ```bash
    python -m venv .venv
    ```
-   **Activate virtual environment (if not already activated):**
    ```bash
    .\.venv\Scripts\activate
    ```
-   **Select interpreter from Visual Studio Code (if not already selected):**
    Open the Command Palette (Ctrl+Shift+P), search for the Python: Select Interpreter command, and select it (e.g. .venv\Scripts\python.exe)
-   **Install dependencies (if not already installed):**
    ```bash
    pip install -r requirements.txt
    ```
-   **Parse report:**
    ```bash
    py .\scripts\parse_all_tests_metrics.py  
    ```
-   **Generate plot:**
    ```bash
    py .\scripts\plot_status_and_exec_time.py  
    ```

# Data flows

Test Repo (eg. selenium-python-framework), run tests
  pytest -m smoke1 --count=2  (note: --json-report --json-report-file=reports/report.json should be added in toml file, otherwise addit to the command line)
    ↓
  report.json (artifact)
    ↓ 
Test Metrics Analyzer, run parsers and plotters modules
  copy artifact in data\input\ e.g. data\input\report.json
    ↓
  parser_exec_time_get_all_tests.py
    ↓
  data\output\parser_exec_time_get_all_tests.json (artifact)
    ↓
  plot_status_and_exec_time scripts
    ↓
  plots\plot_status_and_exec_time.png (artifact)
